# 搜索结果过度页规划

本规划旨在设计一个**移动端 H5** 健康搜索过度页，通过建立用户信任、提供有价值内容和优化转化路径，提升问诊 agent 页面的互动率和最终转化率。

## 产品形态

- **载体**：移动端 H5 页面（适配手机浏览器、微信内嵌 WebView 等场景）
- **视口**：以 375px 宽度为基准设计，单列纵向布局，无左右分栏
- **交互**：触控优先，按钮与可点击区域满足移动端最小点击热区（≥ 44px）
- **首屏**：核心内容与问诊入口均在首屏可见，避免横向滚动

## 一、核心能力梳理

### 1. 内容匹配与展示能力
- **搜索词智能匹配**：根据用户搜索关键词动态生成相关健康科普内容
- **结构化内容呈现**：将 AI 生成的内容人工整理为固定模版，确保内容质量和可读性
- **多模版支持**：针对不同类型搜索词（用药类、症状类、减重调理类、辨证类等）设计差异化内容模版

**典型搜索词举例**（用于模版设计与方案验证）：

| 搜索词 | 类型 | 推荐方案 |
|--------|------|----------|
| 120斤怎么瘦到90斤 | 减重/调理目标 | 方案A 或 方案C |
| 999优力元益血生胶囊的功效与作用 | 药品功效 | 方案A |
| 36岁男人可以吃六味地黄丸吗 | 人群 + 用药咨询 | 方案D |
| 50岁女人夜里潮热怎么回事 | 人群 + 症状 | 方案D |
| 一动满头大汗吃什么药好 | 症状 + 用药 | 方案B 或 方案A |
| 一招判断风寒还是风热 | 辨证/自测 | 方案B |

### 2. 信任建立能力
- **互联网医院专业背书**：以「成都青羊榕树家互联网医院」作为唯一专业信任锚点，展示卫健委可查、统一社会信用代码等资质信息
- **弱化个人医生形象**：页面不出现医生头像、医生姓名、职称头衔等个人化元素；不使用「专家」「名医」等指向具体人的表述
- **机构化表达**：统一使用「互联网医院」「在线问诊」「AI 健康助手」等机构与服务层面的措辞
- **专业内容背书**：通过 AI 生成 + 人工整理的内容模式，传递专业性和权威性
- **服务保障说明**：强调隐私保障、7×24 在线等服务优势

### 3. 互动引导能力
- **首屏单列布局**：纵向排列有价值内容与问诊 agent 入口，满足移动端浏览和转化需求
- **多样化引导方案**：设计多种互动钩子，如症状自查、快速问答、个性化建议等
- **渐进式转化**：通过轻量级互动逐步引导用户进入深度问诊

### 4. 服务扩展能力
- **底部服务入口**：将 AI 舌诊作为页面底部的独立服务入口，点击进入专门的舌诊工具落地页
- **交叉引流**：在主要内容转化路径外，提供其他健康服务的入口

## 二、设计思路方案

> 以下方案均按**移动端 H5 单列布局**设计，不考虑 PC 端左右分栏。

### 方案A：内容优先型（适合知识密集型搜索词）

**适用场景**：用户搜索具体健康知识或药品信息

**典型搜索词**：`999优力元益血生胶囊的功效与作用`、`120斤怎么瘦到90斤`

**首屏布局**（自上而下）：
- 顶部：互联网医院品牌标识 + 搜索词标题
- 中部：结构化内容卡片（功效/作用/注意事项/调理建议等）
- 底部固定栏：悬浮「在线问诊」按钮（机构化文案，无医生形象）

**互动引导设计**：
1. **内容内嵌引导**：在内容段落中插入「想了解更多？在线咨询」链接
2. **症状/话题标签**：内容下方展示相关标签，点击触发「您也有类似情况？让 AI 帮您分析」
3. **知识延伸引导**：内容底部显示「相关话题」，点击后进入问诊 agent 继续探讨

**转化路径**：用户浏览内容 → 话题共鸣 → 点击标签/链接 → 进入问诊 agent

### 方案B：互动优先型（适合症状导向、辨证类搜索词）

**适用场景**：用户搜索具体症状、用药诉求或需要快速判断的问题

**典型搜索词**：`一动满头大汗吃什么药好`、`一招判断风寒还是风热`

**首屏布局**：
- 顶部：互联网医院品牌标识 + 问题标题
- 中部：快速自查/辨证工具（3–5 个选择题，触控友好）
- 下部：相关科普内容折叠展示（可上滑展开）

**互动引导设计**：
1. **快速自查/辨证**：首屏直接展示轻量问卷，用户选择后给出「建议进一步在线问诊」的引导
2. **个性化建议**：根据选择结果生成建议卡片，卡片底部嵌入「获取详细方案」按钮
3. **对比分析**：展示「常见情况 vs 您的情况」对比，强化问题认知，引导问诊

**转化路径**：用户完成自查 → 获得初步结果 → 点击获取详细方案 → 进入问诊 agent

### 方案C：平衡型（适合目标导向、综合性搜索词）

**适用场景**：用户搜索较为宽泛或有明确目标的健康话题

**典型搜索词**：`120斤怎么瘦到90斤`（亦可与方案 A 组合验证）

**首屏布局**：
- 顶部：互联网医院品牌标识 + 目标/话题标题
- 中部上：核心科普内容摘要（3–4 个要点卡片）
- 中部下：「AI 智能分析」引导卡片（与内容同屏，纵向紧邻）
- 底部固定栏：「开始咨询」入口

**互动引导设计**：
1. **内容 + 引导卡片纵向排列**：先呈现价值内容，紧接着展示问诊引导卡片
2. **内容锚点**：点击引导卡片可跳转到对应内容段落
3. **阅读进度提示**：用户浏览时，引导卡片显示「已了解 XX%，可以继续在线咨询」

**转化路径**：用户浏览内容 → 引导卡片持续可见 → 点击咨询 → 进入问诊 agent

### 方案D：场景化型（适合特定人群搜索词）

**适用场景**：用户搜索带有明确人群特征（年龄、性别）的健康问题

**典型搜索词**：`36岁男人可以吃六味地黄丸吗`、`50岁女人夜里潮热怎么回事`

**首屏布局**：
- 顶部：互联网医院品牌标识 + 人群标签（如「36 岁男性」「50 岁女性」）+ 核心问题
- 中部：场景化内容（以典型情况/常见问题形式呈现，非医生案例故事）
- 底部：针对性互动引导 + 固定「在线问诊」入口

**互动引导设计**：
1. **场景共鸣**：以「您是否也有以下情况」开头，列出与该人群相关的典型表现
2. **分步引导**：「了解情况 → 获取建议 → 在线问诊」三步流程，每步一屏或一卡片
3. **及时性提示**：在场景描述中强调「症状持续或加重时，建议及时在线问诊」，不制造恐慌

**转化路径**：用户场景共鸣 → 跟随分步引导 → 点击在线问诊 → 进入问诊 agent

## 三、模版分类策略

### 模版1：药品功效类
**适用搜索词**：具体药品名称、功效、作用、副作用等  
**示例**：`999优力元益血生胶囊的功效与作用`  
**内容结构**：药品简介、主要功效、适用人群、注意事项、用药提醒  
**互动引导**：相关症状标签、用药咨询入口（机构化文案）

### 模版2：症状咨询类
**适用搜索词**：具体症状、身体不适、何时就医等  
**示例**：`50岁女人夜里潮热怎么回事`、`一动满头大汗吃什么药好`  
**内容结构**：症状描述、可能原因、缓解方法、何时需要问诊  
**互动引导**：快速自查、症状评分、AI 分析入口

### 模版3：减重调理类
**适用搜索词**：减重目标、体质调理、养生保健等  
**示例**：`120斤怎么瘦到90斤`  
**内容结构**：目标解读、科学原则、生活建议、饮食与运动方向  
**互动引导**：目标评估、个性化方案生成、咨询入口

### 模版4：人群用药类
**适用搜索词**：特定年龄、性别人群能否用药、如何用药等  
**示例**：`36岁男人可以吃六味地黄丸吗`  
**内容结构**：人群特点、药品说明、适用与禁忌、建议行动  
**互动引导**：场景化引导、分步问诊、在线问诊入口

### 模版5：辨证自测类
**适用搜索词**：风寒风热判断、体质辨识等需要用户参与的问题  
**示例**：`一招判断风寒还是风热`  
**内容结构**：简要科普 + 自测题 + 结果解读 + 进一步问诊建议  
**互动引导**：快速辨证工具、结果卡片、问诊入口

## 四、关键设计原则

### 1. 移动端首屏转化原则
- 内容和问诊入口必须在首屏同时可见（纵向排列）
- 底部固定栏或悬浮按钮承载主转化入口，避免用户需大量滚动才能找到
- 按钮尺寸与间距满足触控操作习惯

### 2. 信任传递原则（机构背书，弱化个人医生）
- 互联网医院品牌标识在页面顶部显著位置
- 资质信息（卫健委可查、信用代码）在首屏或次屏展示
- **禁止**：医生头像、医生姓名、职称、个人简介、「专家坐诊」等个人化展示
- **推荐文案**：「成都青羊榕树家互联网医院」「在线问诊」「AI 健康助手」「卫健委备案」
- 内容标注「AI 生成 + 人工整理」，传递专业性

### 3. 互动渐进原则
- 从轻量级互动（点击标签、单选自查）开始，逐步引导到深度问诊
- 避免一次性要求用户提供过多信息
- 互动控件适配移动端（大按钮、少步骤）

### 4. 内容价值原则
- 内容必须与搜索词高度相关，解决用户的即时信息需求
- 内容结构清晰，便于手机端快速扫读
- 避免过度营销，保持内容的客观性和专业性

## 五、数据指标与优化

### 核心指标
- **转化率**：从过度页进入问诊 agent 的用户比例
- **停留时间**：用户在过度页的平均停留时长
- **互动率**：用户点击互动元素（标签、自查等）的比例
- **跳出率**：用户进入过度页后直接离开的比例

### 优化方向
- A/B 测试不同互动引导方案的效果（以本文第六节搜索词为测试集）
- 根据搜索词类型优化模版匹配策略
- 分析移动端用户行为路径，优化内容布局与底部固定转化入口
- 持续优化内容质量，强化互联网医院机构信任感
