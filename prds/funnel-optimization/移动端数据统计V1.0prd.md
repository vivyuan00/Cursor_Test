## 1. 需求背景与目标

### 1.1 业务背景

平台已建设 Web 端「全链路漏斗 / 多维度数据统计」能力，覆盖每日转化、订单金额、医助人效、医助成交与渠道维度分析。老板与管理层在移动场景下仍缺少**轻量、可读、可下钻**的经营看板：无法在手机上快速查看今日加粉/成交、分渠道表现、获客成本趋势与医助 Top。

本需求在**复用 Web 端既有数据口径与汇总模型**的前提下，面向移动端交付「素灵CRM数据看板」，优先服务老板侧看数决策。

### 1.2 需求目标

| 目标编号 | 目标描述 | 衡量方式 |
| -------- | -------- | -------- |
| G01 | 提供移动端登录与个人中心，保障老板看板可安全访问 | 登录 / 记住我 / 退出流程 UAT 通过 |
| G02 | 首页可一览今日加粉、成交、分渠道与医助成交 Top，并跳转详情 Tab | 首页模块齐全，入口跳转正确 |
| G03 | 加粉 / 成交 / 渠道 / 医助人效 / 医助成交五类详情页可筛选、看图、看表 | 与 Web 端核心指标口径抽样对账通过 |

### 1.3 需求范围

**包含**：

| 编号 | 功能名称 | 功能描述 | 优先级 |
| ---- | -------- | -------- | ------ |
| F01 | 登录与会话 | 账号密码登录、记住我、会话保持 | P0 |
| F02 | 个人中心 | 展示用户名、手机号、所属部门、所属角色；退出登录 | P0 |
| F03 | 首页经营总览 | 今日实时 KPI、分渠道核心、订单核心、近 7 天医助成交 Top5 | P0 |
| F04 | 加粉 | 近一个月默认范围；加粉数趋势 + 平均获客成本趋势；明细表 | P0 |
| F05 | 成交 | 近一个月默认范围；初复诊×汤丸剂堆叠图 + 多系列趋势折线；明细表 | P0 |
| F06 | 渠道 | 快捷/自定义时间；渠道加粉 / 初诊成交 / 获客成本 Top5 条形图；明细表 | P0 |
| F07 | 医助人效 | 默认今日；加粉-支付转化率 Top5；明细表 | P0 |
| F08 | 医助成交 | 默认今日；总订单数 / 总订单金额 Top5（上下结构）；明细表 | P0 |

**不包含**（V1.0）：

- Web 端完整漏斗条形图（AI 工具转化 / 医助转化漏斗全链路）
- 渠道→子渠道→产品→版本树形钻取与「产品详细转化」页
- 来源多选、过滤重复添加、子渠道/产品/版本级投流隐藏规则的完整实现（移动端 V1.0 简化筛选）
- 导出 Excel、查询/重置按钮组（移动端以即时筛选刷新为主）
- 医助开方转化率排行（移动端仅保留支付转化率 Top）
- 渠道「点击-加粉转化率」排行图

> **口径原则**：未在本文单独改写的指标定义，一律以《多维度数据统计》PRD 为准；本文仅描述移动端展示裁剪与交互差异。

## 6. 页面与交互

### 6.1 页面结构

**系统名称**：素灵CRM数据看板  

**整体结构**：

```
登录页
  ↓ 登录成功
顶栏 Tab：首页 | 加粉 | 成交 | 渠道 | 医助人效 | 医助成交  + 头像入口（个人中心）
  ↓
各业务页：筛选区（如有）→ 图表区 → 数据表
```


### 6.2 登录页

| 元素 | 说明 |
| ---- | ---- |
| 系统名 | 素灵CRM数据看板 |
| 账号 | 必填输入 |
| 密码 | 必填输入 |
| 记住我 | 勾选后下次带出账号（及现网策略允许的记住项） |
| 登录 | 提交校验；失败提示「账号或密码不能为空 / 错误」 |

### 6.3 个人中心

| 字段 | 说明 |
| ---- | ---- |
| 用户名 | 登录账号或展示名 |
| 手机号 | 脱敏展示（如 138\*\*\*\*6688） |
| 所属部门 | 组织架构部门名 |
| 所属角色 | 如老板看板管理员 |
| 退出登录 | 二次确认后退出 |

入口：顶栏右侧头像；支持返回首页。

### 6.4 首页

#### 6.4.1 今日实时

| 卡片 | 指标 | 口径说明 | 交互 |
| ---- | ---- | -------- | ---- |
| 今日加粉数（全量） | 当日加粉总量 + 较昨日涨跌幅 | 全部渠道新增企微好友人数（含非 AI 工具来源，如线下转介绍等）；按加粉事件计 | 点击进入「加粉」 |
| 今日成交订单数 | 当日支付成功订单数 + 较昨日涨跌幅 | 当日全部支付成功订单数（初诊 + 复诊） | 点击进入「成交」 |

#### 6.4.2 今日分渠道核心数据

- 按渠道汇总加粉倒序列出渠道（中文名）
- 每渠道展示：今日加粉、今日初诊成交及较昨日涨跌
- 入口：「渠道 ›」

#### 6.4.3 今日订单核心数据

- 初诊：订单数 / 金额，拆分汤剂、丸剂
- 复诊：订单数 / 金额，拆分汤剂、丸剂
- 入口：「成交 ›」

#### 6.4.4 近 7 天医助成交 Top

| 图表 | 内容 | 格式 |
| ---- | ---- | ---- |
| 总订单数 Top5 | 近 7 天医助总订单数 Top5，带序号 | 横向条形图，上下布局之一 |
| 总订单金额 Top5 | 近 7 天医助总订单金额 Top5，带序号 | 横向条形图，上下布局之二 |

约束：最多 5 条、不滚动、左右留白、条长受控。入口：「医助成交 ›」。

### 6.5 加粉

#### 6.5.1 筛选项

| 筛选项 | 类型 | 默认值 | 说明 |
| ------ | ---- | ------ | ---- |
| 时间 | 日期范围（半宽） | 近一个月 | 点击弹出开始/结束日期；标题「时间」 |
| 平台 | 下拉 | 全部 | 抖音 / 百度 / 微信 / 快手 / 小红书 等 |
| 渠道 | 下拉 | 全部 | 选项展示中文名，值映射渠道编码 |
| 团队 | 下拉 | 全部 | A 组 / B 组 / C 组 等 |

筛选项两列紧凑布局；筛选变更后即时刷新图表与表（V1.0）。

#### 6.5.2 图表

| 图表 | 内容 | 交互 |
| ---- | ---- | ---- |
| 加粉数趋势 | 按日 **加粉数（全量）** 折线，含纵轴 | 点击数据点展示当日数值 |
| 平均获客成本趋势 | 按日平均获客成本折线，含纵轴 | 点击数据点展示当日数值 |

> 加粉数趋势与首页「今日加粉数（全量）」口径一致；表中仍保留加粉数（渠道汇总）用于投流转化与获客成本计算。

#### 6.5.3 数据表

| 列名 | 口径说明 |
| ---- | -------- |
| 日期 | 业务日，按自然日统计 |
| 投流消耗 | 当日投放消耗金额合计（元） |
| 行为点击 | 当日投放行为点击次数 |
| 加粉数（渠道汇总） | 各投放渠道新增加企微好友人数（含 AI 工具添加及投放企微卡等）；用于计算投流转化与获客成本 |
| 行为点击-加粉转化率 | 加粉数（渠道汇总）÷ 行为点击 |
| 平均获客成本 | 投流消耗 ÷ 加粉数（渠道汇总）；加粉数为 0 时展示「—」 |
| 加粉数（全量） | 全部渠道新增企微好友人数（含非 AI 工具来源，如线下转介绍等）；按加粉事件计；置于末列；与加粉数趋势图口径一致 |

表支持横向滚动查看完整列。

### 6.6 成交

#### 6.6.1 筛选项

与「加粉」一致：时间（默认近一个月）、平台、渠道、团队；两列布局，时间占半宽。

#### 6.6.2 图表

| 图表 | 内容 | 格式 |
| ---- | ---- | ---- |
| 订单数 | 初诊 / 复诊 / 总计，汤剂+丸剂堆叠 | 左右双卡堆叠柱 |
| 订单金额 | 同上，金额维度 | 左右双卡堆叠柱 |
| 趋势折线图 | 可切换「订单金额 / 订单数」；系列：总计 + 初诊汤剂/丸剂 + 复诊汤剂/丸剂 | 全宽折线；点击展示当日各系列数值 |

图例：汤剂、丸剂颜色区分；趋势图系列图例展示在图下方。

#### 6.6.3 数据表

| 列名 | 口径说明 |
| ---- | -------- |
| 日期 | 业务日，按自然日统计 |
| 合计单 | 当日全部支付成功订单数（初诊 + 复诊） |
| 合计额 | 当日全部支付成功订单实付金额合计（元） |
| 初诊单 | 当日初诊支付成功订单数 |
| 初诊额 | 当日初诊订单实付金额合计（元） |
| 复诊单 | 当日复诊支付成功订单数 |
| 复诊额 | 当日复诊订单实付金额合计（元） |
| 汤剂单 | 当日药物类型为汤剂的支付成功订单数 |
| 汤剂额 | 当日汤剂订单实付金额合计（元） |
| 丸剂单 | 当日药物类型为丸剂的支付成功订单数 |
| 丸剂额 | 当日丸剂订单实付金额合计（元） |

### 6.7 渠道

#### 6.7.1 筛选项

| 筛选项 | 类型 | 默认值 | 说明 |
| ------ | ---- | ------ | ---- |
| 时间 | 快捷标签 + 自定义 | 今日 | 今日 / 昨日 / 近7天 / 近30天；自定义为按钮+文案，点击选开始/结束日期 |
| 平台 | 下拉 | 全部 | 同加粉 |
| 渠道 | 下拉 | 全部 | 中文名展示 |

#### 6.7.2 图表（纵向依次）

| 图表 | 排序规则 | 格式 |
| ---- | -------- | ---- |
| 渠道加粉 Top5 | 加粉数倒序 | 横向条形图 + Top 序号 |
| 初诊成交 Top5 | 初诊成交订单倒序 | 横向条形图 + Top 序号 |
| 获客成本 Top5 | 平均获客成本升序（越低越好） | 横向条形图 + Top 序号 |

约束：最多 5 条、不滚动、条长受控、左右留白。

#### 6.7.3 数据表

| 列名 | 口径说明 |
| ---- | -------- |
| 渠道 | 渠道中文名称 |
| 投流消耗 | 该渠道在筛选时段内的投放消耗金额（元）；无投流时展示「—」 |
| 行为点击 | 该渠道在筛选时段内的投放行为点击次数；无投流时展示「—」 |
| 加粉数（渠道汇总） | 该渠道新增加企微好友人数（含 AI 工具添加及投放企微卡等） |
| 行为点击-加粉转化率 | 加粉数（渠道汇总）÷ 行为点击；行为点击为 0 时展示「—」 |
| 平均获客成本 | 投流消耗 ÷ 加粉数（渠道汇总）；无投流或加粉为 0 时展示「—」 |
| 初诊成交订单 | 该渠道初诊支付成功订单数 |
| 加粉-初诊成交转化率 | 初诊成交订单 ÷ 加粉数（渠道汇总）；加粉为 0 时展示「—」 |

## 7. 异常处理

| 异常场景 | 触发条件 | 处理规则 | 提示信息 |
| -------- | -------- | -------- | -------- |
| 登录校验失败 | 账号或密码为空 | 阻止登录 | 账号或密码不能为空 |
| 登录鉴权失败 | 账号密码错误 | 阻止登录 | 账号或密码错误 |
| 未登录访问 | 会话失效仍打开业务页 | 跳转登录页 | — |
| 时间范围非法 | 开始日期晚于结束日期 | 阻止确认 | 开始日期不能晚于结束日期 |
| 无数据 | 筛选后结果为空 | 图表展示「暂无数据」，表为空态 | 暂无数据 |
| 无投流渠道 | 消耗/点击为 0 | 获客成本、转化率展示「—」 | — |
| 退出确认 | 点击退出登录 | 二次确认 | 确认退出登录？ |

## 8. 非功能需求
