# 数仓分层、主题域与自助取数规范

> **目标**：支撑 T+1 BI、角色画像、专题分析，并让各业务方在 **统一口径** 下自助取数。  
> **关联**：[2026-05-14-指标与维度字典.md](./2026-05-14-指标与维度字典.md)

---

## 一、分层模型（ODS / DWD / DWS / ADS）

| 层级 | 命名前缀（建议） | 职责 | 是否对业务开放 SQL |
|------|------------------|------|---------------------|
| **ODS** | `ods_` | 贴源同步，保留源系统字段与分区；轻清洗（类型、空值标记），**不改业务含义** | 仅数据工程 / 排障 |
| **DWD** | `dwd_` | 明细事实 + 维度整合，统一主键（`user_id`、`role_id`）、时间、枚举规范化 | **是（主分析层）** |
| **DWS** | `dws_` | 按主题、按日/周汇总；轻度退化维度（如 channel_id） | **是** |
| **ADS** | `ads_` | 面向应用：BI 宽表、画像宽表、流失/拉黑专题表 | **是（推荐）** |

**依赖原则**：ADS → 仅依赖 DWD/DWS；DWS → 依赖 DWD；DWD → 依赖 ODS。禁止 ADS 直连 ODS。

## 三、「探索区」与集市表

### 3.1 探索区（Sandbox）

- **用途**：分析师临时查询、PoC；**禁止**作为 CRM 生产策略或对外报表的唯一定期数据源。  
- **规范**：个人库 `sandbox_${user}`；对象生命周期 30 天自动回收（可配）；不得复制明文 PII 出生产边界。

### 3.2 数据集市（Mart）

| 集市名称 | 受众 | 内容 |
|----------|------|------|
| **mart_ops_funnel** | 运营 / 增长 | 日漏斗汇总、渠道切片、素材（若有） |
| **mart_ops_role_profile** | 运营 / CRM | `role_id` 画像宽表、标签长表视图 |
| **mart_service_quality** | 服务主管 | 医助响应、签字耗时、拉黑/流失关联 |
| **mart_finance**（可选） | 财务 | GMV、退款、对账字段；字段级权限更严 |

集市在物理上对应 **ADS + 部分 DWS**；通过 **视图** 暴露给不同角色（见安全文档）。

## 四、自助取数规范（业务方「打捞数据」）

### 4.1 允许查询对象

- **推荐**：`dws_*`、`ads_*`、经审批的 `dwd_*` 视图（脱敏）。  
- **禁止**：直接查 ODS（除数据工程角色）；跨库 `select *` 无分区限定。

### 4.2 SQL 规范（强制）

- **分区裁剪**：所有查询必须带 `where pt between ...` 或 `pt = 'yyyy-MM-dd'`。  
- **主键意识**：画像/标签分析 **默认 `role_id`**；账号级问题显式 `join dwd_dim_user`。  
- **去重**：漏斗人数用 `count(distinct ...)` 时，在注释中说明去重键。  
- **大结果集**：单次导出 >10 万行走工单与脱敏导出通道。

### 4.3 文档配套

- 每张对外表需有 **数据字典**（字段、类型、样例、负责人、血缘链接）。  
- 提供 **样例 SQL 包**（Git 或内部 Wiki）：漏斗日汇总、角色画像取数、医助排行。

## 五、命名与生命周期（建议）

| 类型 | 模式 | 示例 |
|------|------|------|
| 事实表 | `dwd_fact_<业务>_di` | `dwd_fact_order_di` |
| 维度表 | `dwd_dim_<实体>` | `dwd_dim_user` |
| 汇总表 | `dws_<主题>_<粒度>_1d` | `dws_funnel_channel_1d` |
| 应用表 | `ads_<场景>_<粒度>` | `ads_role_profile_1d` |

**生命周期**：ODS 在线保留 90～180 天（合规允许前提下）；DWD 明细与分区策略按存储成本评估；ADS 可较短保留 + 回溯重跑。

---

## 六、与 BI 的衔接

- BI 数据集 **优先绑定 ADS/DWS**；若直连 DWD，需通过 **语义层视图** 隐藏敏感列。  
- 每张 BI 卡片注明：**指标编码**（见指标字典）、**统计粒度**、**刷新周期 T+1**。
