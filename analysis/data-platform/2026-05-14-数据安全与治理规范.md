# 数据安全与治理规范

> **适用范围**：数据仓库、标签、BI、导出与 CRM 对接。  
> **合规背景**：健康数据、互联网诊疗相关个人信息需 **最小必要、脱敏、可审计**。

---

## 一、数据分级

| 级别 | 示例 | 存储 | 分析区 | BI 默认 |
|------|------|------|--------|---------|
| L4 核心健康 | 完整病历、舌象原图 URL、对话全文 | 生产加密 | 禁止入 ADS 默认列 | 禁止 |
| L3 身份联系 | 手机号、身份证、真实姓名 | 生产加密 | ODS 受限；DWD 仅存 hash/脱敏 | 禁止 |
| L2 业务敏感 | 支付流水号、openid | 内网 | DWD 受限角色 | 部分 |
| L1 运营统计 | 汇总 GMV、漏斗人数、标签枚举 | 内网 | DWD/DWS/ADS | 可 |

---

## 二、脱敏规则（建议）

| 字段 | 规则 |
|------|------|
| mobile | 保留前 3 后 4，或仅 hash |
| id_card_no | 仅保留年龄/性别衍生列，不入宽表原文 |
| real_name | 默认不入 ADS；必要时「姓+先生/女士」 |
| transcript / conversation_log | 不入数仓宽表；专题仅统计量 |
| image_url | 替换为内网代理令牌 URL 或仅保留 diagnosis_id |

---

## 三、权限与角色

| 角色 | ODS | DWD | DWS/ADS | 导出 |
|------|-----|-----|---------|------|
| data_engineer | RW | RW | RW | 审批 |
| analyst | R（视图） | R（视图） | R | 脱敏 + 限额 |
| ops_channel_X | 无 | 无 | R（channel 行过滤） | 禁止 raw |
| assistant_manager | 无 | 无 | R（本组 assistant） | 审批 |
| admin | 按最小化授予 | | | 审计 |

**实现**：数仓 **Row policy** / BI 数据集 RLS；统一经 **LDAP/SSO 组** 映射。

---

## 四、审计

- 记录：**谁、何时、查询了哪张表/看板、是否导出、行数估计**。  
- 日志保留 ≥ 180 天（按公司合规要求调整）。  
- 敏感看板 **水印**（账号 + 时间）。

---

## 五、环境隔离

| 环境 | 数据 | 用途 |
|------|------|------|
| prod | 真实数据 | 生产调度、正式 BI |
| staging | 脱敏或子集 | 联调、BI UAT |
| dev | 假数据 | 开发 |

**禁止**：从 prod 手工 copy 全量明文到个人笔记本。

---

## 六、质量与血缘（治理）

- **血缘**：至少表级；核心指标争取字段级（DataHub / 云血缘）。  
- **SLA**：T+1 任务在 **06:00** 前成功；失败 P1 告警。  
- **质量规则**：见 [数据采集与对账](./2026-05-14-数据采集与入仓对账设计.md) Q001–Q005。

---

## 七、标签伦理

- 标签用途限于 **服务改进与合规运营**；禁止未经法务评估的歧视性策略。  
- `calc_version` 变更需 **留档与回溯**。
