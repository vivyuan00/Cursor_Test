# T+1 BI 看板与工具选型

> **刷新周期**：默认 **每日一次**（如 06:00 前）；数据集绑定 `pt` 最大分区。  
> **关联**：[指标与维度字典](./2026-05-14-指标与维度字典.md)、[DWD/DWS](./2026-05-14-DWD-DWS模型清单.md)

---

## 一、选型原则（必选项）

| 原则 | 说明 |
|------|------|
| **行级/列级权限** | 渠道运营仅能看本渠道；医助看本人或本组 |
| **SSO** | 与运营后台统一登录（OIDC / SAML） |
| **嵌入** | iframe 或官方 SDK 嵌入医助/管理后台 |
| **审计** | 导出、查看敏感看板留痕 |
| **T+1 明确标注** | 卡片标题或副标题注明「数据截至昨日」 |

---

## 二、候选工具对比（简表）

| 产品类型 | 代表产品 | 优点 | 注意 |
|----------|----------|------|------|
| 国内云 BI | Quick BI、网易有数 等 | 与云数仓集成顺、权限模型成熟 | 厂商绑定 |
| 开源 BI | Apache Superset、Metabase | 成本低、可自建 | SSO/权限需二次开发 |
| 企业级 | FineBI、Tableau 等 | 运营友好 | 许可成本 |

**PoC 建议**：2 周内用 **同一份 ADS 数据集**（`dws_funnel_*` + `ads_role_profile_wide_1d`）接两套中任选其一做对比（见总体方案中的 PoC）。

## 三、看板目录（MVP）

### 3.1 全链路转化漏斗（T+1）

| 页签 / 卡片 | 数据源 | 维度下钻 |
|-------------|--------|----------|
| 全链路总览 | `dws_funnel_channel_assistant_1d` 或 `dwd_fact_funnel_event_di` 聚合 | 日期、channel |
| 素材效果（若有 material_id） | 同上 + 素材维 | material |
| 医助排行（权限内） | `dws_funnel_channel_assistant_1d` | assistant |
| 步骤间转化率 | 计算字段 | — |

**验收**：与业务抽样 **100 单** 人工核对 F09/F10 人数与金额。

### 3.2 用户维度分析（实为 **角色维度**）

| 页签 / 卡片 | 数据源 | 说明 |
|-------------|--------|------|
| 角色画像分布 | `ads_role_profile_wide_1d` | 交易分档、服务阶段饼图 |
| 健康标签分布 | 画像或 `health_tags` 解析 | 脱敏层级 |
| 沉默 / 流失趋势 | `ads_role_churn_daily` | 按 pt 折线 |
| 拉黑专题 | `ads_role_block_assistant_daily` | 与对照组对比在自助分析中完成 |

### 3.3 账号级大盘（可选）

| 页签 | 数据源 | 说明 |
|------|--------|------|
| 账号 GMV / 付费人数 | `dws_user_roll_up_1d` | **独立入口**，标题注明 user 粒度 |

## 四、数据集与 SQL 视图建议

- `v_bi_funnel_1d`：`select * from dws_funnel_channel_assistant_1d where pt <= current_date-1`。  
- `v_bi_role_profile_1d`：基于 `ads_role_profile_wide_1d` 脱敏视图。  
- 禁止 BI 直连 ODS。
