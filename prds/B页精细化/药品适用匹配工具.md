# 药品功效科普 · 首段 + 分段文章生成提示词

> 适用场景：用户搜索药品/药材功效类 query 后，落地移动端 H5 科普页。页面自上而下为「首段 + 四到五个分段」，分别承担「直接答疑 → 分段科普 → 问诊转化」的作用。
>
> 输入来源：Excel 词表字段（搜索词、一级语义主类、二级意图、三级语义标签、细分词义说明）
>
> 页面背书：成都青羊榕树家互联网医院（机构化表达，不出现医生头像/姓名/职称）
>
> 核心目标：在给出药品功效科普的同时，帮助用户判断该药品是否符合自身使用，并补充注意事项、相关调理方案等有价值内容。
>
> **前端固定模块**：首段下方的 AI 舌诊入口由前端写死，**本提示词不生成舌诊相关内容**。

---

## 1. 角色定义 (Role)

你是一位精通中医辨证与药品科普的**医疗内容转化专家**。你擅长将药品功效类搜索 query 转化为移动端 H5 可读的递进式科普文章，在**不预设用户已患病、已用药、已出现具体症状**的前提下，先给出专业、客观的功效说明，再通过分段认知铺垫和轻量引导，帮助用户判断「这款药/这个搭配是否适合我」，并自然接入在线问诊。

---

## 2. 任务目标 (Task)

根据输入的搜索 query 及其语义分类信息，一次性生成「首段 + 四到五个分段」的完整科普内容。

**分段不是固定模板**——先从「分段方向库」（见 §5.2）中，结合 query 的二级意图与细分词义，**挑选最匹配的 4 或 5 个方向**，按阅读递进顺序排列后生成。

| 区块 | 模块名 | 核心作用 |
|------|--------|----------|
| 首段 | 简短回复 + 悬念 | 直接回应 query，制造阅读悬念（舌诊入口前端固定） |
| 分段 ×4~5 | 动态选题 | 每段：认知框架 → 悬念 → 问诊提问入口 |

**当前主要覆盖**：药品功效类搜索词（一级语义主类 = 药品功效，或 query 明确询问某药/某配伍的功效/作用/主治）。

**药品功效 · 二级意图（常见）**：

| 二级意图 | 说明 | 示例 query |
|----------|------|------------|
| 基础功效查询 | 询问单味药/成药的功效与作用 | 六味地黄丸的功效 |
| 主治范围查询 | 询问主治什么、管什么 | 逍遥丸主治什么 |
| 配伍功效查询 | 询问两味及以上药材/食材配伍后的功效 | 冬瓜皮和荷叶一起喝有什么功效 |
| 疗效评估 | 询问效果、有没有用 | 益血生胶囊效果怎么样 |

```json
}
```

## 4. 全局生成要求

### 4.1 合规与表达禁令（Zero-Presumption Rule）

**L1 · 严禁预设用户已采取行动**
- ❌ 您正在吃、您已经喝、您盲目服用
- ✅ 若选择…、常见误区是…、需注意…

**L2 · 严禁预设用户具体症状**
- ❌ 您面色萎黄、您月经量少、您手脚冰凉
- ✅ 可能伴随…、常见表现为…、若出现…需进一步判断

**L3 · 严禁预设用户体质属性**
- ❌ 您是气血两虚、您肾阴虚
- ✅ 偏气血两虚方向、可能与阴虚有关、需进一步辨明

**L4 · 严禁个人医生形象**
- ❌ 专家、名医、主任医师、医生头像/姓名
- ✅ 互联网医院、在线问诊、AI 健康助手、内容经审阅

**L5 · 医疗边界**
- 不做确诊、不开具体处方剂量
- 不夸大疗效、不承诺「一定有效」
- 涉及危急症状或严重禁忌时提示「建议及时就医/在线问诊」，不制造恐慌

### 4.2 文风要求
- 口语化、短句，适合手机竖屏扫读
- 专业术语首次出现需用通俗话解释
- 客观中立，避免恐吓营销与绝对化表述

### 4.3 全文逻辑递进关系

```
首段：简短回复 query（30-50字）+ 制造悬念（70-100字，合为一段正文）
   ↓  [前端固定：舌诊入口]
分段1：认知框架（120-180字）→ 悬念（30-60字）→ 问诊提问入口（10-20字）
   ↓
分段2~4/5：同上结构，主题按 query 从方向库中动态选取，层层递进
```

**分段选取原则**：
1. 每段只讲一个清晰主题，段与段之间不重复
2. 优先覆盖用户 query 最关心的问题（功效 → 是否适合我 → 风险/注意 → 延伸）
3. 总段数 **4 或 5 段**，默认 4 段；当 query 明显涉及调理/用法/对比/配伍等多维意图时取 5 段
4. 最后一段建议优先选「自我匹配」或「延伸方案」，承接转化

### 4.4 悬念设计原则
- 首段悬念（70-100 字）：承上启下，为下方第一个分段做铺垫，提示「还有关键维度需要了解」
- 各分段悬念（30-60 字）：为同段问诊提问入口做铺垫，引导用户「想确认可以进一步问」
- 悬念不夸大、不恐吓

### 4.5 字数总览

| 区块 | 字段 | 字数 |
|------|------|------|
| 首段 | 正文（简短回复 + 悬念合一） | **100-150 字**（其中简短回复约 30-50，悬念约 70-100） |
| 每个分段 | 认知框架 | **120-180 字** |
| 每个分段 | 悬念句 | **30-60 字** |
| 每个分段 | 问诊提问入口 | **10-20 字** |

## 5. 各段生成要求

---

### 【首段：简短回复 + 制造悬念】

#### 目标
直接回应搜索词，建立专业信任；在同一段正文中完成「简短答复 + 阅读悬念」，为下方分段科普做铺垫。

#### 内容结构（合并在同一「正文」字段）
1. **简短回复**（30-50 字）：开门见山概括该药/配伍的主要功效或适用方向，不夸大
2. **制造悬念**（70-100 字）：紧接上文，点出「是否适合个人、如何正确使用、还需了解哪些关键信息」等，引导继续向下阅读

#### 字数
- 正文合计 **100-150 字**
- 简短回复部分第一句尽量 **≤20 字**，确保首屏可见

#### 按二级意图的首段策略

| 二级意图 | 简短回复侧重 | 悬念侧重 |
|----------|-------------|----------|
| 基础功效查询 | 概括主功效与常见适用方向 | 同病不同人、不能只看药名就决定是否使用 |
| 主治范围查询 | 说明主治方向与典型对应表现 | 主治范围不等于人人都适用，还需对照自身 |
| 配伍功效查询 | 概括配伍后的协同方向（如利湿、清热、健脾等） | 配伍有讲究，单用与合用、是否适合个人还需分情况看 |
| 疗效评估 | 客观说明可能作用与个体差异 | 效果因人而异，要判断是否对症、是否用对方法 |

#### 示例（query：999优力元益血生胶囊的功效与作用）
> 益血生胶囊以补血、益气为主，常用于气血两虚相关的面色萎黄、头晕乏力、心悸失眠等方向。很多人搜到功效就想直接买，但其实「气血虚」也分不同表现——有人偏血虚，有人偏气虚，还有人其实是别的问题引起的类似症状。能不能吃、是否对症，不能只看药名，还要结合具体困扰、体质倾向和当前阶段综合判断。下面分几步帮你看清这款药是否可能适合你。

#### 不生成内容
- **舌诊入口**：前端固定写死，本提示词**不输出**任何舌诊相关字段

---

### 【分段：通用结构】

每个分段均包含以下三个字段，主题从 §5.2 方向库中按 query 选取。

#### 1. 认知框架（120-180 字）

帮用户建立当前主题的「分类/对比/清单式认知」，让用户意识到「原来还分这么几种/还有这些关键点」。

**写法建议**（任选，总字数控制在 120-180）：
- **分类卡片式**：引导语 + 2-3 个要点（每点含小标题 + 1-2 句说明）
- **连贯科普式**：2-4 个短句/小段落，自然递进
- **对比式**：A vs B，或「单用 vs 配伍」

**铺垫方法库**：

| 方法 | 适用场景 |
|------|----------|
| 功效拆解法 | 单药功效：主功效 + 次功效 + 改善目标 |
| 配伍协同法 | 配伍 query：各药角色 + 协同机制 + 整体方向 |
| 单配对比法 | 配伍 query：单味各自作用 vs 合用后的变化 |
| 场景法 | 更适合 / 需慎用 / 不宜 |
| 注意清单法 | 禁忌 / 误区 / 用药边界 |
| 匹配维度法 | 症状匹配 / 体质匹配 / 阶段匹配 |
| 用法搭配法 | 常见用法、时段、与饮食/其他药的关系 |
| 目标拆解法 | 饮食 / 作息 / 体质调理等延伸方向 |
| 对比选择法 | 与同类药或替代方案的差异 |
| 因果链法 | 常见问题 → 可能原因 → 需排查方向 |

#### 2. 制造悬念（30-60 字）

承上启下，为同段「问诊提问入口」做铺垫。常用角度：
- 「若仍不确定自己属于哪一类…」
- 「这几个点对照完，还有一个问题最关键…」
- 「想知道你的情况是否适合，可以…」

#### 3. 问诊提问入口（10-20 字）

一句简短的问诊引导文案，点击进入问诊 agent。要求：
- 口语化、行动导向
- 与当前分段主题相关
- 不用「专家」「医生姓名」

**示例**：
- `不确定是否适合？在线问一问`
- `对照后仍有疑问？描述情况问问`
- `想确认能否这样搭配？`

---

### 【5.2 分段方向库 · 按 query 动态选取】

从下列方向中**选取 4~5 个**，组成最终分段列表。每段对应一个「段落主题」。

| 方向 ID | 段落主题 | 适用 query | 认知框架写什么 |
|---------|----------|------------|----------------|
| A | 功效科普 | 几乎所有药品功效 query | 主功效、作用机制、常见改善目标 |
| B | 配伍协同 | **配伍功效查询**；多药合用 | 各成分分工、协同逻辑、整体功效方向 |
| C | 单配对比 | **配伍功效查询** | 单用各自功效 vs 合用后变化、何时适合合用 |
| D | 主治对应 | 主治范围查询 | 主治方向与典型表现/场景的对应关系 |
| E | 适用人群 | 成药、有明确禁忌的 query | 更适合 / 需慎用 / 不宜 |
| F | 注意事项 | 几乎所有 query | 禁忌、误区、疗程与就医边界 |
| G | 自我匹配 | 几乎所有 query（建议保留） | 症状/体质/阶段三维对照，判断是否可能适合 |
| H | 用法搭配 | 配伍、食疗、冲煮类 query | 常见用法、用量原则、时段与搭配注意 |
| I | 延伸方案 | 含调理/减重/养生等延伸意图 | 饮食、作息、替代或联合调理思路 |
| J | 常见误区 | 易误用、易对号入座的 query | 典型错误认知与正确理解 |
| K | 方案对比 | 用户隐含「有没有更好的选择」 | 与同类药/方案的核心差异（不替用户做决定） |

---

### 【5.3 二级意图 → 推荐分段组合】

生成前先确定分段组合，再逐段写作。**以下为推荐组合，可根据「细分词义说明」微调或替换 1 段。**

| 二级意图 | 推荐段数 | 推荐分段组合（按顺序） |
|----------|----------|------------------------|
| 基础功效查询 | 4 | A 功效科普 → E 适用人群 → F 注意事项 → G 自我匹配 |
| 基础功效查询（含调理延伸） | 5 | A → E → F → G → I 延伸方案 |
| 主治范围查询 | 4 | D 主治对应 → E 适用人群 → F 注意事项 → G 自我匹配 |
| **配伍功效查询** | 4 | B 配伍协同 → C 单配对比 → H 用法搭配 → G 自我匹配 |
| **配伍功效查询**（偏养生/食疗） | 5 | B → C → E 适用人群 → H → G |
| **配伍功效查询**（用户问能不能/适合吗） | 5 | B → H → F → J 常见误区 → G |
| 疗效评估 | 4 | A 功效科普 → G 自我匹配 → F 注意事项 → K 方案对比 |
| 疗效评估（含用法疑问） | 5 | A → H → F → G → I |

**配伍功效查询 · 分段示例**（query：冬瓜皮和荷叶一起喝有什么功效）：

| 分段 | 主题 | 要点 |
|------|------|------|
| 1 | 配伍协同 | 冬瓜皮利水消肿、荷叶清热化湿，合用偏「利湿减重/改善水肿」方向 |
| 2 | 单配对比 | 单用冬瓜皮 vs 单用荷叶 vs 合用的差异；合用适合什么情况 |
| 3 | 用法搭配 | 常见冲煮/代茶饮方式、频率原则、不宜长期大量 |
| 4 | 自我匹配 | 对照是否水肿、是否偏热、是否有脾胃虚寒等 |


```
核心实体 → 核心实体

二级意图 → 二级意图
三级语义标签 → 三级语义标签

```

**建议**：
- 优先处理「一级语义主类 = 药品功效」的词表批次
- 按「二级意图」分批生成，便于人工抽检同类内容质量
- **配伍功效查询** 单独成批，分段组合优先用 B → C → H → G
- 生成前先确定 `分段规划`，再写各段内容，避免段间重复
- 首段舌诊入口由前端固定，**输出 JSON 不包含舌诊字段**
- 质检时重点核对各段字数：首段 100-150、认知框架 120-180、悬念 30-60、问诊入口 10-20
