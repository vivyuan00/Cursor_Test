1. 项目背景与目标

1.1 背景

当前业务需要跟踪用户从“添加企微医助” → “沟通” → “开方” → “支付成交”的全流程转化数据。管理人员需要在一个页面上查看所有原始明细，并能够按多种维度筛选，以定位不同渠道、医助的转化效率。

1.2 目标

  1. 数据透明：展示所有添加医助的用户明细，包含线索、沟通、成交三大模块的全部字段。
  2. 高效筛选：提供基于时间、渠道、医助、状态等多维度筛选，支持快捷日期切换。
  3. 高效浏览：支持表格横向滚动、分页，关键字段合并展示，次要详情折叠。
  4. 数据导出：支持将筛选后的数据导出为 Excel 文件。

2. 功能范围（Scope）

2.1 包含功能

  • 多维度筛选器（含快捷日期）
  • 统计卡片（4个核心指标）
  • 数据明细表（含三级折叠详情）
  • Excel 数据导出
  • 分页

3. 详细功能需求

3.1 筛选器

筛选项控件类型数据源/规则说明
时间快捷按钮组今日/昨日/近7天/近30天默认选中“今日”，基于加粉时间筛选
加粉日期起止日期选择器-联动快捷按钮，支持自定义区间
所属渠道下拉单选动态读取联动“子渠道”
子渠道下拉单选根据所选渠道加载渠道变更时重置选项
所属团队下拉单选B组 / ...运营公司字段
医助名文本输入模糊匹配支持输入医助账号别名或企微id进行搜索
响应状态下拉单选优良/良好/一般/较差根据首末次响应间隔计算，详见以下说明
开方状态下拉单选已开方/未开方根据首单编号是否为空判断
成交状态下拉单选已成交/未成交根据支付时间是否为空判断
昵称/编号文本输入模糊匹配支持患者微信名/编号搜索

交互逻辑：

  • 任何筛选条件变化后，需点击“筛选”按钮生效。
  • “重置”按钮将清空所有筛选条件并恢复默认（今日数据）。

3.2 统计卡片

卡片名称计算口径说明
添加用户数筛选范围内加粉用户总数以用户和医助为一组信息，若1个用户加2个医助算2条数据；若一个用户添加一个医助后删除又添加算1条数据
已开口用户筛选范围内用户对话数 > 0 的用户数以用户和医助为一组信息，若1个用户和2个医助都开口算2条数据；添加后系统发送的欢迎语“已添加xx开始对话吧”不算
成交用户数筛选范围内用户产生的初诊订单的用户数-
总成交金额筛选范围内首单金额之和单位：元

3.3 数据明细表

3.3.1 表头结构

表格共 15列，分为三大区块，支持横向滚动。

所属团队所属业务组-

成交状态已成交/未支付/--

3.3.2 折叠详情内容

  • 沟通详情：客户首次对话时间、医助首次对话时间、首轮间隔(秒)、客户末次对话时间、医助末次对话时间、末次间隔(秒)。
  • 开方详情：首单编号、开单医生、首单金额、首单创建时间。
  • 支付详情：首单支付时间、物流发货时间、进线成交天数（加粉到首单支付间隔时间，单位是天和时）。

3.3.3 状态判定规则

间隔计算口径：

  • 首轮间隔 = 医助首次时间 − 患者首次时间（无医助回复时取当前系统时间）
  • 末次间隔 = 医助末次时间 − 患者末次时间（医助末次早于患者末次时取当前系统时间）
状态名称判定逻辑前端样式
响应状态(优良)首轮间隔 ≤ 3分钟 且 末次间隔 ≤ 3分钟绿色徽章
响应状态(良好)首轮间隔 ≤ 10分钟 且 末次间隔 ≤ 10分钟，且不满足「优良」黄色徽章
响应状态(一般)至少一项 ≤ 10分钟，且不满足「良好」橙色徽章
响应状态(较差)首轮间隔 > 10分钟 且 末次间隔 > 10分钟红色徽章

3.4 分页

  • 每页显示 10 条数据。
  • 支持“上一页”、“下一页”按钮翻页。
  • 显示当前页/总页数。

3.5 数据导出

  • 触发：点击“导出Excel”按钮。
  • 范围：导出当前筛选条件下的全部数据（不分页）。
  • 格式：.xlsx (Excel) 文件。
