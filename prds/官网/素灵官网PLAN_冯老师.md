# 素灵AI 官网 实施计划

## Summary
- 建一个中文单页官网，只介绍素灵AI的中医科技，不介绍业务模式、融资、估值、收入、市场规模、价格或增长计划。
- 视觉基准采用最新“更科幻”概念图。
- 技术风格参考 Apple/SpaceX 的高级科技感，但不复制品牌：黑场首屏、Three.js 全屏 3D 流体/粒子背景、渐变发光、电路几何、滚动视差与发光路径动效。
- 交付形态：React + Vite 官网首版，中文内容，针对SEO进行优化，大众与专业人士兼顾。

## Key Changes
- 页面结构：
  - 首屏 Hero：`以人工智能重构中医科技`，全屏 Three.js 背景，文字直接叠在场景上，不放卡片。
  - 技术底座：中医语义系统、中医知识图谱、多模态识别、隐私计算与数据安全。
  - 多模态诊疗流程：舌象采集、问诊语音转写、病历信息抽取、辨证辅助、医师复核。
  - 专家智能体：展示名医辨证思路的结构化沉淀与持续校准。
  - 全周期健康算法：体质辨识、慢病管理、随访调衡、治未病。
  - 合规安全：执业医师审核、诊疗全程留痕、数据安全、医疗合规。
- 品牌标识：无正式 logo 文件时，使用“抽象几何科技标识 + 素灵AI”文字组合。
- 动效实现：
  - Three.js 首屏全屏 Canvas，包含流体感核心、粒子场、电路线、轻微鼠标响应。
  - 滚动时触发发光路径、区块淡入、视差移动。
  - 支持 `prefers-reduced-motion`，降级为静态或低频动画。
- 内容边界：
  - 必须明确 AI 是辅助工具，关键诊疗环节保留“医师复核”。
  - 禁止出现融资、估值、营收、盈利、商业模式、市场规模、转化率、获客、供应链商业闭环等商业计划内容。

## Interfaces / Types
- 无后端 API，无用户登录、表单提交或医疗问诊功能。
- 前端用配置数据驱动内容：
  - `navItems`
  - `techPillars`
  - `diagnosisSteps`
  - `agentHighlights`
  - `healthAlgorithmItems`
  - `complianceItems`
- Three.js 组件暴露参数：主题色、粒子密度、动画强度、是否降级动画。

## Test Plan
- 运行 `npm run build`，确保构建通过。
- 本地启动后用浏览器检查桌面与移动端布局。
- 验证 Three.js 首屏非空白、可见、不卡住，并且移动端不会遮挡标题。
- 检查 `prefers-reduced-motion` 下动画降级可用。
- 做文案审计：页面不得出现商业模式、融资、估值、收入、市场规模、价格等内容。
- 检查核心合规表达：AI 辅助、医师复核、数据安全、诊疗留痕必须清晰可见。

## Assumptions
- 使用当前 PDF 中的技术内容作为文案依据，只抽取中医科技相关信息。
- 暂无正式 logo、品牌字体或视觉规范，首版采用自制抽象标识。
- 官网首版只做静态展示和前端动效，不提供真实诊疗、问诊、预约或后台能力。
