## 1. 需求背景与目标

### 1.1 业务背景

业务除中药处方订单外，已上线益生元、肠道检测、基因检测、营养剂等**商品类**履约。V1.1 移动端看板的成交相关指标仅覆盖中药（初诊/复诊 × 汤剂/丸剂/颗粒剂），无法反映商品贡献，运营与团队考核口径不完整。

### 1.2 需求目标

| 目标编号 | 目标描述 | 衡量方式 |
|----------|----------|----------|
| G01 | 成交类核心指标支持中药+商品全量统计 | 首页、成交、团队模块总订单/GMV 与明细加总一致 |
| G02 | 商品可按四类类目下钻 | 首页核心数据、成交堆叠柱、成交明细表均支持四类拆分 |
| G03 | 保持 V1.1 中药统计口径不变 | 中药指标与 V1.1 对账一致，商品为增量 |

### 1.3 需求范围

**包含（本版本）**：

| 编号 | 功能 | 优先级 |
|------|------|--------|
| F01 | 首页：今日实时 / 订单核心数据 / 团队 Top / 医助 Top 商品口径 | P0 |
| F02 | 成交 Tab：趋势图、订单数据统计卡、明细表 | P0 |
| F03 | 团队 Tab · 医助成交：数据表与 Top 图商品口径 | P0 |

**不包含**：

- PC 端多维数据看板 V1.2（另案）
- 渠道维、每日转化维的商品订单统计（本版仅改首页/成交/团队成交相关）
- 商品库存、退款明细、SKU 级下钻

## 3. 核心统计口径

### 3.1 订单类型定义

| 类型 | 定义 | 子类 |
|------|------|------|
| **中药订单** | 支付成功的中药处方订单 | 初诊中药、复诊中药；剂型：汤剂、丸剂、颗粒剂 |
| **商品订单** | 支付成功的非处方商品订单 | 益生元、肠道检测、基因检测、64款营养剂 |
| **总订单** | 当日/时段内全部支付成功订单 | **总订单 = 初诊中药 + 复诊中药 + 商品订单** |

### 3.2 金额口径

| 指标 | 口径 |
|------|------|
| 中药总订单额 | 初诊中药实付 + 复诊中药实付 |
| 商品订单额 | 四类商品实付合计 |
| 成交 GMV | 中药总订单额 + 商品订单额 |
| 净 GMV | 扣除退款后的成交 GMV（**含商品**） |

### 3.3 医助维度

| 指标 | 口径 |
|------|------|
| 中药总单 / 中药总额 | 该医助（或团队）服务用户产生的中药订单数/额 |
| 商品单 / 商品额 | 该医助（或团队）关联的商品订单数/额 |
| 总单 / 总额 / 总客单价 | 中药 + 商品合计；客单价 = 总额 ÷ 总单（总单为 0 展示「—」） |

## 4. 功能需求（按页面）

### 4.1 首页

#### 4.1.1 今日实时 `[3]`

| 指标 | 主值 | 弱字段 | 副行（昨日） |
|------|------|--------|--------------|
| 加粉数（全量） | 今日加粉 | — | 昨日加粉 |
| **成交订单数** | 初诊中药+复诊中药+商品 | **无**（不展示「商品 X 单」） | 昨日同口径 |
| 初诊转化率 | 初诊订单数÷进粉数 | 初诊订单数 | 昨日转化率 |
| **成交 GMV** | 中药+商品实付合计 | **净 GMV**（扣退款，含商品） | 昨日 GMV |

- 点击成交订单数 / 成交 GMV / 初诊转化率 → 进入「成交」Tab

#### 4.1.2 今日订单核心数据 `[4]`

三块纵向卡片，自上而下：

| 块 | 标题行 | 弱字段明细 |
|----|--------|------------|
| 初诊（中药） | X 单 / ¥金额 | 汤剂、丸剂、颗粒剂 各单数/金额 |
| 复诊（中药） | X 单 / ¥金额 | 汤剂、丸剂、颗粒剂 各单数/金额 |
| **商品** | X 单 / ¥金额 | 益生元、肠道检测、基因检测、64款营养剂 各单数/金额 |

#### 4.1.3 今日团队 Top

- 排序：按团队**初诊转化率**倒序
- 每团队 **7 张**指标卡横向滑动（一屏约 2.5 张，多团队行同步联动滑动）

| 指标卡 | 弱字段 |
|--------|--------|
| 初诊转化率 | 加粉数、初诊订单数 |
| **医助人均接粉量** | 加粉数、接线医助数 |
| 初诊客单价 | — |
| 复诊客单价 | — |
| **中药总订单数** | 中药总订单额 |
| **商品订单数** | 商品订单金额 |
| 平均对话轮次 | 总对话轮次 |

> 首页团队 Top **不展示**「医助人均初诊成单量」；该指标仅在团队 Tab 数据表中展示。

#### 4.1.4 近 7 天医助成交 Top

| 图表 | 口径 |
|------|------|
| 总订单数 Top5 | 近 7 天医助**中药+商品**订单数 |
| 总订单金额 Top5 | 近 7 天医助**中药+商品**订单金额 |

### 4.2 成交 Tab `[6]`

**筛选项**：与 V1.1 一致——时间（默认近一个月）、平台、渠道、团队；即时刷新。

**卡片顺序**（自上而下）：

1. 趋势折线图  
2. 订单数据统计  
3. 数据表  

#### 4.2.1 趋势折线图（第一屏）

- Tab：**订单金额** / **订单数**（右上角）
- **默认展示 4 条系列**：

| 订单金额模式 | 订单数模式 |
|--------------|------------|
| 总金额 | 总订单 |
| 初诊中药 | 初诊中药 |
| 复诊中药 | 复诊中药 |
| 商品 | 商品 |

- 图例位于折线下方
- **展开剂型数据**（勾选框，默认不勾选）：勾选后在上述 4 条基础上**追加** 6 条：
  - 初诊汤剂、初诊丸剂、初诊颗粒剂
  - 复诊汤剂、复诊丸剂、复诊颗粒剂
- 不勾选时**不展示**上述 6 条剂型线（初诊中药/复诊中药汇总线仍保留）

#### 4.2.2 订单数据统计（第二屏）

- **一张卡片**合并中药与商品（不再分两张卡）
- Tab：**订单金额** / **订单数**
- 横向 **3 根堆叠柱**：

| 柱 | 堆叠维度 |
|----|----------|
| 初诊（中药） | 汤剂、丸剂、颗粒剂 |
| 复诊（中药） | 汤剂、丸剂、颗粒剂 |
| 商品 | 益生元、肠道检测、基因检测、64款营养剂 |

- 图例含中药三剂型 + 四类商品

#### 4.2.3 数据表

三级表头，按日期展示，支持横向滚动：

| 分组 | 列 |
|------|-----|
| 初诊（中药） | 汤剂/丸剂/颗粒剂/合计 × 订单数、金额 |
| 复诊（中药） | 同上 |
| 中药合计 | 同上 |
| 商品订单 | 四类商品 + 合计 × 订单数、金额 |
| 全部合计 | 订单数、金额 |

---

### 4.3 团队 Tab · 医助成交 `[8]`

二级 Tab：**医助成交** | **医助人效**（人效 Tab 无本版变更）

#### 4.3.1 医助成交 · 图表

| 图表 | 说明 |
|------|------|
| 团队初诊转化率 Top5 | 同 V1.1 |
| 团队客单价 Top5 | 初诊/复诊 Tab 切换，同 V1.1 |
| **总订单 Top5** | Tab 订单金额/订单数；统计**中药+商品** |

#### 4.3.2 医助成交 · 数据表

默认团队聚合，点击「+」展开医助明细；列顺序：

加粉 → 接线医助 → **医助人均接粉量** → 初诊单/额/客单价/转化率/**医助人均初诊成单量** → 复诊单/额/客单价 → **中药总单/额/客单价** → **商品单/额** → **总单/额/客单价**

| 列 | 说明 |
|----|------|
| 医助人均接粉量 | 团队接粉总数 ÷ 接线医助数；仅团队汇总行展示 |
| 医助人均初诊成单量 | 初诊订单数 ÷ 接粉医助数；仅团队汇总行展示 |
| 中药总单/额/客单价 | 仅中药（初诊+复诊） |
| 商品单/额 | 四类商品合计 |
| 总单/额/客单价 | 中药 + 商品 |

## 5. 指标字典（V1.2 新增/变更）

| 指标名 | 定义 |
|--------|------|
| 成交订单数 | 当日全部支付成功订单数（初诊中药+复诊中药+商品） |
| 成交 GMV | 全部支付成功订单实付金额（中药+商品）；弱字段为净 GMV |
| 商品订单数 | 四类商品支付成功订单数合计 |
| 商品订单额 | 四类商品实付金额合计 |
| 中药总订单数 | 初诊中药订单数 + 复诊中药订单数 |
| 中药总订单额 | 初诊中药实付 + 复诊中药实付 |
| 总单（医助/团队） | 初诊中药单 + 复诊中药单 + 商品单 |
| 总额（医助/团队） | 初诊中药额 + 复诊中药额 + 商品额 |
| 总客单价 | 总额 ÷ 总单；总单为 0 时展示「—」 |
| 医助人均接粉量 | 团队接粉总数 ÷ 接线医助数；接线医助数为 0 时展示「—」 |
| 医助人均初诊成单量 | 初诊订单数 ÷ 接粉医助数；接粉医助数为 0 时展示「—」 |

## 6. 交互与展示规则

| 规则编号 | 规则 |
|----------|------|
| R01 | 首页今日实时：成交订单数、成交 GMV **不展示**商品拆分弱字段 |
| R02 | 商品明细拆分仅出现在：首页订单核心数据、成交堆叠柱、成交明细表 |

## 7. 数据对账要求

| 对账项 | 规则 |
|--------|------|
| 首页成交订单数 | = 首页订单核心数据（初诊中药单+复诊中药单+商品单） |
| 首页成交 GMV | = 上述三块金额之和 |
| 团队中药总单 + 商品单 | = 团队维度总单 |
| 成交表「全部合计」 | = 中药合计 + 商品合计 |
| 与 V1.1 中药部分 | 同筛选条件下，中药指标与 V1.1 一致 |
