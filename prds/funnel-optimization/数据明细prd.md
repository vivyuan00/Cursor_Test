## 1. 项目背景与目标
### 1.1 背景
当前业务需要跟踪用户从“添加企微医助” → “沟通” → “开方” → “支付成交”的全流程转化数据。管理人员需要在一个页面上查看所有原始明细，并能够按多种维度筛选，以定位不同渠道、医助的转化效率。

### 1.2 目标
1.  **数据透明**：展示所有添加医助的用户明细，包含线索、沟通、成交三大模块的全部字段。
2.  **高效筛选**：提供基于时间、渠道、医助、状态等多维度筛选，支持快捷日期切换。
3.  **高效浏览**：支持表格横向滚动、分页，关键字段合并展示，次要详情折叠。
4.  **数据导出**：支持将筛选后的数据导出为 Excel 文件。


## 2. 功能范围（Scope）
### 2.1 包含功能
-   多维度筛选器（含快捷日期）
-   统计卡片（4个核心指标）
-   数据明细表（含三级折叠详情）
-   Excel 数据导出
-   分页


## 3. 详细功能需求

### 3.1 筛选器
| 筛选项 | 控件类型 | 数据源/规则 | 说明 |
| :--- | :--- | :--- | :--- |
| **时间快捷** | 按钮组 | 今日/昨日/近7天/近30天 | 默认选中“今日”，基于**加粉时间**筛选 |
| **加粉日期起止** | 日期选择器 | - | 联动快捷按钮，支持自定义区间 |
| **所属渠道** | 下拉单选 | 动态读取 | 联动“子渠道” |
| **子渠道** | 下拉单选 | 根据所选渠道加载 | 渠道变更时重置选项 |
| **所属团队** | 下拉单选 | B组 / ... | 运营公司字段 |
| **医助名** | 文本输入 | 模糊匹配 | 支持输入医助账号别名或企微id进行搜索 |
| **响应状态** | 下拉单选 | 优良/良好/一般/较差 | 根据首末次响应间隔计算，祥见以下说明 |
| **开方状态** | 下拉单选 | 已开方/未开方 | 根据首单编号是否为空判断 |
| **成交状态** | 下拉单选 | 已成交/未成交 | 根据支付时间是否为空判断 |
| **昵称/编号** | 文本输入 | 模糊匹配 | 支持患者微信名/编号搜索 |

**交互逻辑**：
-   任何筛选条件变化后，需点击“筛选”按钮生效。
-   “重置”按钮将清空所有筛选条件并恢复默认（今日数据）。

### 3.2 统计卡片
| 卡片名称 | 计算口径 | 说明 |
| :--- | :--- | :--- |
| 添加用户数 | 筛选范围内加粉用户总数 | 以用户和医助为一组信息，若1个用户加2个医助算2条数据 ；若一个用户添加一个医助后删除又添加算1条数据|
| 已开口用户 | 筛选范围内用户对话数 > 0 的用户数 | 以用户和医助为一组信息，若1个用户和2个医助都开口算2条数据；添加后系统发送的欢迎语“已添加xx开始对话吧”不算 |
| 成交数 | 筛选范围内用户产生的初诊订单数 | - |
| 总成交金额 | 筛选范围内首单金额之和 | 单位：元 |

### 3.3 数据明细表
#### 3.3.1 表头结构
表格共 **15列**，分为三大区块，支持横向滚动。

| 区块 | 列名 | 字段来源 | 备注 |
| :--- | :--- | :--- | :--- |
| **线索信息** | 患者(编号/昵称) | 微信名 + 编号 | 昵称主显示，编号副显示 |
| | 医助(名/账号) | 医助名 + 账号 | 姓名主显示，账号副显示 |
| | 所属团队 | 所属业务组 | - |
| | 渠道 | 所属渠道 | - |
| | 子渠道 | 子渠道 | - |
| | 报告时间 | 报告时间 | - |
| | 加粉时间 | 加粉时间 | - |
| | 状态标识 | 正常/重复添加/已删除 | 一个用户添加一个医助为正常，添加多个医助为重复添加，用户已删除该医助为删除 |
| **沟通信息** | 客户对话数 | 客户对话数 | - |
| | 医助回复数 | 医助对话数 | - |
| | 图片数 | 客户图片数 | - |
| | 响应状态 | “优良/良好/一般/较差”  | - |
| **成交信息** | 开方状态| 已开方/未开方｜根据该用户和医助检索是否有开方信息 | -|
| | 成交状态 | 已成交/未支付/- | - |

#### 3.3.2 折叠详情内容
-   **沟通详情**：客户首次对话时间、医助首次对话时间、首轮间隔(秒)、客户末次对话时间、医助末次对话时间、末次间隔(秒)。
-   **开方详情**：首单编号、开单医生、首单金额、首单创建时间。
-   **支付详情**：首单支付时间、物流发货时间、进线成交天数（加粉到首单支付间隔时间，单位是天和时）。

#### 3.3.3 状态判定规则

**间隔计算口径**：
- 首轮间隔 = 医助首次时间 − 患者首次时间（无医助回复时取当前系统时间）
- 末次间隔 = 医助末次时间 − 患者末次时间（医助末次早于患者末次时取当前系统时间）

| 状态名称 | 判定逻辑 | 前端样式 |
| :--- | :--- | :--- |
| 响应状态(优良) | 首轮间隔 ≤ 3分钟 且 末次间隔 ≤ 3分钟 | 绿色徽章 |
| 响应状态(良好) | 首轮间隔 ≤ 10分钟 且 末次间隔 ≤ 10分钟，且不满足「优良」 | 黄色徽章 |
| 响应状态(一般) | 至少一项 ≤ 10分钟，且不满足「良好」 | 橙色徽章 |
| 响应状态(较差) | 首轮间隔 > 10分钟 且 末次间隔 > 10分钟 | 红色徽章 |

### 3.4 分页
-   每页显示 **10** 条数据。
-   支持“上一页”、“下一页”按钮翻页。
-   显示当前页/总页数。

### 3.5 数据导出
-   **触发**：点击“导出Excel”按钮。
-   **范围**：导出当前筛选条件下的**全部数据**（不分页）。
-   **格式**：`.xlsx` (Excel) 文件。
