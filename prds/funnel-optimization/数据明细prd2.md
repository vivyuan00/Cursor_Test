## 1. 需求背景与目标

### 1.1 业务背景

本轮改造的核心目的，是**拓展明细数据的可筛范围与使用场景**：在既有「加粉时间」口径上增加「支付时间」维度、在核心列表补充支付时间与复诊信息、补充应用/应用版本筛选，使明细页不仅能独立排查个案，还能承接全链路漏斗汇总表的下钻——从漏斗任意汇总行一键跳入明细，并自动带入对应日期、渠道、医助等筛选条件。

| 问题 | 现状 | 影响 |
|------|------|------|
| 时间维度单一 | 仅支持按「加粉时间」筛选 | 无法按支付节点复盘转化，也无法承接漏斗「支付/订单」口径下钻 |
| 成交信息过简 | 成交信息分列且字段不足 | 初诊/复诊成交细节不足，无法与漏斗订单口径对齐 |
| 加粉状态不可筛 | 列表展示加粉状态，但无筛选项 | 无法快速定位重复添加、已删除用户 |
| 漏斗与明细割裂 | 汇总表无法一键进入明细 | 运营需手工重选筛选条件，排查效率低 |
| 导出超时 | 同步导出，前端一次性拉取全量数据生成 Excel | 筛选数据量大时导出失败，影响运营取数 |

### 1.2 需求目标

| 目标编号 | 目标描述 | 衡量方式 |
|----------|----------|----------|
| G01 | 支持加粉/支付双时间维度，筛选与统计口径随维度切换 | 切换后筛选项、统计卡片、列表、趋势图口径一致 |
| G02 | 核心列表直接展示支付时间与复诊关键字段 | 无需展开详情即可查看支付时间、复诊次数/时间 |
| G03 | 全链路漏斗汇总表可一键下钻至明细 | 各表操作列链接带入正确时间维度与筛选项 |
| G04 | 支持大数据量场景下的稳定数据导出 | 10 万条以内筛选结果异步导出成功率 ≥ 99% |

| 应用 / 应用版本 | 下拉 | 全部 | 始终 | 版本随应用联动 |

#### 3.2.1 时间维度切换规则

| 时间维度 | 列表命中逻辑 | 筛选项 | 统计卡片 |
|----------|--------------|--------|----------|
| 加粉时间（默认） | 加粉时间落在日期范围内 | 展示加粉状态、响应状态、初诊开方/初诊成交/复诊成交状态 | 见 3.5「加粉时间」卡片集 |
| 支付时间 | 初诊支付或任一复诊支付时间落在日期范围内即命中；两端均无支付则不命中 | **隐藏**加粉状态、响应状态、初诊开方状态、初诊成交状态、复诊成交状态 | 见 3.5「支付时间」卡片集 |

**交互说明**：

1. 切换时间维度后，快捷文案、日期标签、筛选项显隐、统计卡片布局同步更新；已选日期范围**保留不清空**。
2. 支付时间维度下被隐藏的筛选项不参与查询（等同于「全部」）。
3. 页脚说明同步更新当前时间维度。

#### 3.2.2 应用与应用版本筛选规则

| 应用 | 可选版本 |
|------|----------|
| 舌诊 | v3.2、v2.1 |
| 体质测试 | v3.2、v1.0 |
| 问诊H5 | v2.1、v1.0 |

切换应用后版本重置为「全部」。

#### 3.2.3 状态筛选规则

**加粉状态**：

| 展示值 | 判定规则 |
|--------|----------|
| 正常 | 是否删除 = 否 且 重复添加 = 否 |
| 重复添加 | 重复添加 = 是（优先于已删除） |
| 已删除 | 是否删除 = 是 且 重复添加 = 否 |

**初诊开方状态**：已开方 = 存在初诊处方；未开方 = 无。

**初诊成交状态**：已成交 = 初诊支付成功；未成交 = 未支付（含未开方）。

**复诊成交状态**：已成交 = 复诊次数 > 0；未成交 = 复诊次数 = 0。


### 3.3 漏斗汇总表下钻明细（U05）

在全链路漏斗各汇总表**最右侧新增（或调整）操作列**，链接至用户转化明细页，并通过页内跳转带入时间维度与筛选项；明细页落地后自动按带入条件执行一次筛选。


| 来源页面 | 操作文案 | 带入明细的筛选条件 |
|----------|----------|-------------------|
| 每日转化数据 | **加粉明细** | 时间维度=加粉时间；日期起止=该行日期；渠道/子渠道/应用等=当前漏斗筛选条件，【暂时不做过滤用户重复添加多个医助的数据】 |
| 每日转化数据 | **支付明细** | 时间维度=支付时间；日期起止=该行日期；渠道等筛选项带入 |
| 每日订单金额数据 | **数据明细** | 时间维度=支付时间；日期起止=该行日期；渠道等筛选项带入 |
| 医助服务人效统计 | **加粉明细** | 时间维度=加粉时间；日期起止=当前查询日期范围；医助企微 ID（或医助账号）；渠道等筛选项带入 |
| 医助服务人效统计 | **支付明细** | 时间维度=支付时间；日期起止=当前查询日期范围；医助企微 ID；渠道等筛选项带入 |
| 医助成交数据 | **数据明细** | 时间维度=支付时间；日期起止=当前查询日期范围；医助企微 ID；渠道等筛选项带入 |
| 渠道维度数据 | **转化详细**（原「查看详情」改名） | 仍进入渠道产品详细转化页（原逻辑不变） |
| 渠道维度数据 | **加粉明细** | 时间维度=加粉时间；带入该行渠道、子渠道、应用(产品)、应用版本；日期=当前查询范围 |
| 渠道维度数据 | **支付明细** | 时间维度=支付时间；带入同上渠道维度字段；日期=当前查询范围 |


### 3.4 异步导出 Excel（U01）

#### 3.4.1 交互流程

```
用户点击「导出 Excel」
    ↓
校验：是否已执行筛选（detailQueried = true）
    ↓ 否 → Toast「请先筛选数据后再导出」
    ↓ 是
按钮置灰 + 文案变为「导出中...」
    ↓
后端创建导出任务（携带当前全部筛选条件快照）
    ↓
前端轮询任务状态
    ↓
成功 → Toast「导出成功」+ 下载；失败/超时 → 提示原因并恢复按钮
```

#### 3.4.2 导出字段

| 分组 | 导出列 |
|------|--------|
| 线索信息 | 患者编号、患者昵称、医助名、医助账号、所属团队、渠道、子渠道、应用、应用版本、报告时间、加粉时间、加粉状态 |
| 沟通信息 | 患者对话数、医助回复数、患者图片数、响应状态 |
| 成交信息 | 初诊开方状态、初诊支付状态、初诊次数、初诊支付时间、复诊次数、复诊支付时间、总成交次数 |
| 扩展字段 | 开方时间、首单编号、开单医生、首单金额、剂型(汤剂/丸剂)、物流发货时间、成交周期 |

文件命名：`用户转化追踪明细_{时间维度}_{开始日期}_{结束日期}_{导出时间}.xlsx`

### 3.5 统计卡片与趋势图

#### 3.5.1 时间维度 = 加粉时间

| 统计卡片 | 统计口径 | 副文案 |
|----------|----------|--------|
| 添加用户数 | 用户添加医助的数量，1个用户加不同医助算多条，1个用户加同一个医助删了再加算1条 | 去重用户数 x 人 |
| 已开口用户数 | 客户对话数 > 0 的加粉记录数，不算系统欢迎语 | — |
| 初诊成交单数 | 初诊支付成功订单数，如有多名就诊人均成交即多条 | 副文案：汤剂 x 单、丸剂 x 单 |
| 初诊成交金额 | 初诊实付金额合计 | 副文案：汤剂 / 丸剂金额 |
| 复诊成交单数 | 复诊支付成功订单数，多名就诊人多次复诊次数累加 | 副文案：汤剂 x 单、丸剂 x 单 |
| 复诊成交金额 | 复诊实付金额合计 | 副文案：汤剂 / 丸剂金额 |

#### 3.5.2 时间维度 = 支付时间

相比加粉时间筛选，仅保留 4 个成交数据卡片（初诊/复诊成交单数与金额）。

点击卡片切换右侧趋势图聚合指标；对比功能沿用现状，对比基准日期随当前时间维度计算。

趋势图 X 轴：单日按小时、多日按天，时间字段与当前时间维度一致。

### 3.6 核心数据列表（U04）

#### 3.6.2 字段定义

**成交信息**

| 列名 | 说明 | 展示 |
|------|------|------|
| 初诊开方状态 | 是否存在初诊处方 | 已开方 / 未开方 |
| 初诊支付状态 | 初诊是否支付成功 | 已支付 / 未支付 / 未开方 |
| 初诊次数 | 初诊支付成功订单数，如有多名就诊人均成交即多条 | 整数，无为 `0` |
| 初诊支付时间 | 历次初诊支付成功时间 | 单次显示时间；**初诊次数 > 1 时展示多个时间**（换行或分号分隔），否则 `—` |
| 复诊次数 | 复诊支付成功订单数，多名就诊人多次复诊次数累加 | 整数，无为 `0` |
| 复诊支付时间 | 最近一次复诊支付时间 | 有则显示，否则 `—` |
| 总成交次数 | 初诊次数 + 复诊次数 | 整数 |

#### 3.6.3 「更多详情」

- **初诊成交详情**：开方时间、首单编号、开单医生、首单金额、剂型、物流发货时间、**成交周期**；**初诊次数 > 1 时**展示历次初诊支付时间与金额
- **复诊成交详情**（复诊次数 > 0）：历次复诊支付时间、金额、剂型

**成交周期**（仅在「更多详情」中展示）：

| 项 | 说明 |
|----|------|
| 定义 | 首单成交时间与加粉时间的间隔 |
| 单位 | **天**、**时**（例：7天5时） |
| 交互 | 字段名旁展示 **「?」** 图标，hover 显示上述说明 |

#### 3.6.4 字段说明

| 字段 | 说明入口 | 交互 |
|------|----------|------|
| 响应状态 | 列表表头、筛选项标签 | 「?」图标，hover 浮层展示计算公式 + 等级对照表；**浮层 fixed 定位，置于页面最上层** |
| 成交周期 | 「更多详情」内字段标签 | 「?」图标，hover 浮层展示定义与单位（天、时） |
