## 1. 原型范围

| 项 | 说明 |
|----|------|
| 页面 | 首页长滚动（10 模块） |
| 设备 | Mobile（<768px）/ Tablet / Desktop（≥1024px） |
| 样式 | 引用 `src/theme/vars.css`，语义 token，无硬编码品牌色 |
| 视觉 | 品牌绿 + 点缀青，Hero 使用 `--color-bg-brand-gradient` |
| 动效 | CSS 粒子背景占位 Three.js；滚动 fade-in；`prefers-reduced-motion` 降级 |

## 3. Design Token 映射

| 原型元素 | Token |
|----------|-------|
| 页面背景 | `--color-bg-page` |
| 卡片 | `--color-bg-card` + `--radius-card` + `--shadow-md` |
| 主按钮 | `--color-action-primary` + `--radius-button` + `--spacing-56` 高度 |
| 品牌强调 | `--color-text-brand` / `--color-primary-700` |
| 链接 | `--color-text-link` / `--color-accent-700` |
| Hero 背景 | `--color-bg-brand-gradient` |
| 交替区块 | `--color-bg-subtle` |
| 顶栏高度 | `--site-header-h` |

## 4. 交互说明

| 交互 | PC | Mobile |
|------|-----|--------|
| 锚点导航 | 顶栏固定，smooth scroll | 汉堡菜单展开后点击关闭 |
| 微信体验 CTA | hover 显示二维码 popover | 点击滚动至 Hero 二维码 |
| FAQ | 点击 dt 展开/收起 dd | 同左 |
| 滚动入场 | IntersectionObserver fade-in | 同左，reduced-motion 时禁用 |

## 5. 使用方式

1. 确保 `src/theme/vars.css` 路径可访问（相对路径 `../../../src/theme/vars.css`）
2. 用浏览器打开 `素灵AI官网-首页.html`
3. 调整窗口宽度验证 768px / 1024px 断点
4. 切换系统深色模式验证 `prefers-color-scheme: dark` 适配

## 6. 与正式开发的差异

| 原型 | 正式版 |
|------|--------|
| 单 HTML + 外链 vars.css | React + Vite，构建时内联 token |
| CSS 粒子背景 | Three.js 流体/粒子 Canvas |
| 二维码占位块 | 真实小程序码图片 |
| 工具 CTA `#` | H5/小程序深链 + `?from=official_site` |
