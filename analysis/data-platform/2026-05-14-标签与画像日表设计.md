> **关联**：[DWD/DWS 模型清单](./2026-05-14-DWD-DWS模型清单.md)

| 大类编码 | 名称 | 业务用途 | 典型更新 |
|----------|------|----------|----------|
| CAT_HEALTH | 疾病与健康 | 慢病运营、禁忌沟通 | T+1 |
| CAT_TRADE | 交易倾向 | 高潜催付、复购 | T+1 |

| 列名 | 说明 |

| tag_name | 中文名 |

## 三、标签实例长表 `dwd_fact_tag_instance_di`

| 列名 | 类型 | 说明 |
|------|------|------|
| pt | string | 分区，标签 **生效业务日** |
| role_id | bigint | **主粒度** |
| user_id | bigint | 冗余，关联账号 |
| tag_id | bigint | |
| tag_value | string | 枚举编码或数值字符串 |
| source | string | rule / model / crm_sync |
| etl_time | timestamp | |

**唯一约束建议**：`(pt, role_id, tag_id)` 每日一行（多值标签可 `tag_value` 拼 JSON 或拆多行带 `tag_seq`）。

## 四、画像宽表 `ads_role_profile_wide_1d`

**主键**：`(pt, role_id)`  
**生成**：T+1 从长表 pivot + 关联 DWD 维度/事实聚合列。

### 4.1 建议列（首批 v1）

| 列名 | 来源/规则 |
|------|-----------|
| user_id | role 维 |
| channel_id | user 维 |
| relationship | role 维 |
| health_tags_raw | 脱敏或层级化后的标签摘要 |
| tag_* | 各高频标签透视列（如 `tag_trade_potential`） |
| paid_order_cnt_30d | 近 30 日支付订单数 |
| gmv_30d | 近 30 日实付金额 |
| last_paid_date | 最近支付日 |
| last_active_date | 最近活跃日（多源 max） |
| silence_days | `pt` 与 last_active 差 |
| service_stage | 规则引擎输出：如 NEW / CONSULT / UNPAID / PAID / FOLLOWUP |
| risk_blacklist_flag | 平台黑名单 |
| risk_block_wework_flag | 企微侧删除/拉黑（口径见专题文档） |

**禁止**：默认列不得含 **明文手机号、身份证、完整病历文本**。

## 五、首批标签清单（v1 建议）

| tag_code | 大类 | 定义（摘要） |
|----------|------|----------------|
| health_chronic_flag | CAT_HEALTH | health_tags 或病历 ICD 映射为慢病 bool |
| health_tcm_pattern | CAT_HEALTH | 辨证分型粗类（枚举） |
| trade_potential_score | CAT_TRADE | 0–100 规则分：舌诊完成+问诊轮次+未付高潜 |
| trade_paid_cnt_lifetime | CAT_TRADE | 累计付费次数档 |
| trade_aov_band | CAT_TRADE | 历史客单价分档 |
| svc_stage | CAT_SERVICE_STAGE | 状态机当前阶段 |
| svc_overdue_unreply_cnt | CAT_SERVICE_STAGE | 近 7 日超时未回复次数 |
| risk_silence_7d | CAT_RISK | 7 天无有效互动 |
| risk_wework_rel_deleted | CAT_RISK | 企微关系删除/拉黑 |
| ch_first_touch | CAT_CHANNEL | 首触点 channel（与归因一致） |

每条标签需在 `dim_tag_meta` 配 **完整 SQL 伪代码**（实施阶段补全）。

## 六、服务阶段（`svc_stage`）状态机建议

| 状态值 | 进入条件（示例） |
|--------|------------------|
| NEW | 已加微，无有效病历 |
| CONSULT | 有病历草稿或问诊中 |
| WAIT_SIGN | 病历完成，处方待签 |
| WAIT_PAY | 已签字，订单未付 |
| PAID | 已支付 |
| FOLLOWUP | 进入随访计划 |
| SILENT | 超过 N 天无互动且未关闭 |
| CHURN | 满足流失定义 |

具体 N 与「有效互动」定义与 **指标字典** 同步。

## 七、CRM / 策略输出

- **人群包**：`select role_id from dwd_fact_tag_instance_di where pt='...' and tag_id=...` 经审批导出。  
- **回写**：若 CRM 需回写标签，经 API **单向** 由数仓推送版本化结果，避免环写。
